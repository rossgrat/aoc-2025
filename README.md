# Advent of Code 2025

Go solutions and working notes for [Advent of Code 2025](https://adventofcode.com/2025).
Each day is a separate Go module with local input files.

Start with [day 1](day1) or [day 2](day2).
Use the Go version declared in the selected day's `go.mod` and run from that directory:

```sh
cd day1
go run .
```

`main.go` selects the puzzle implementation. Solution-analysis notes record learning and are separate from the runnable code.
